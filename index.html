Política de privacidad

Última actualización: 26 de agosto de 2026

ZetaHub es un proyecto personal de Cesar Sobrino, sin ningún fin comercial. Es un espacio de escaparate para desarrolladores donde mostrar proyectos propios, a modo de portfolio interactivo. No se vende ningún producto ni servicio a través de esta web.

Uso no comercial y sin garantías

Esta web se ofrece "tal cual", con fines personales y de demostración. No se ofrece ninguna garantía de disponibilidad, funcionamiento continuo o ausencia de errores. El autor no se hace responsable de posibles pérdidas de datos, fallos técnicos, interrupciones del servicio o cualquier daño directo o indirecto derivado del uso de esta web.

Datos que se recogen

Esta web puede recopilar información de visita con fines puramente estadísticos (por ejemplo: páginas visitadas, navegador, dispositivo, país aproximado o tiempo de permanencia), habitualmente a través de servicios de analítica del proveedor de hosting (como Vercel Analytics) o herramientas similares. No se recogen datos personales identificativos de forma directa, ni se solicitan formularios, registros ni credenciales.

No se comparten ni venden datos

Los datos estadísticos recogidos no se venden, ceden ni comparten con terceros con fines comerciales. Se usan exclusivamente para entender de forma agregada y anónima cómo se utiliza la web, y así poder mejorarla.

Enlaces externos

Esta web enlaza a perfiles externos (LinkedIn, GitHub) y a proyectos de terceros. ZetaHub no controla ni se responsabiliza de las políticas de privacidad ni del contenido de esos sitios externos una vez el usuario abandona esta página.

Cambios en esta política

Esta política puede actualizarse en cualquier momento para reflejar cambios en la web o en la normativa aplicable. Se recomienda revisar esta página periódicamente.
